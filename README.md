# Bắn lỗi FCIM – tải app Android

App ghi lỗi cho SN trên điện thoại (MK Vision).

## 📲 [Bấm vào đây để tải app (Android)](https://github.com/balacuba/ban-loi-fcim-download/releases/latest/download/BanLoiFCIM.apk)

Link luôn trỏ tới **bản mới nhất**:

```
https://github.com/balacuba/ban-loi-fcim-download/releases/latest/download/BanLoiFCIM.apk
```

## Cách cài

1. Mở link trên bằng **Chrome** trên điện thoại Android (7.0 trở lên).
2. Chrome hỏi tải file `BanLoiFCIM.apk` → bấm **Tải xuống** (nếu cảnh báo "file có thể gây hại", bấm **Vẫn tải xuống**).
3. Mở file vừa tải → Android hỏi *"Cho phép cài ứng dụng từ nguồn này?"* → bật **Cho phép** → quay lại → **Cài đặt**.
4. Đã cài bản cũ: cài đè lên, dữ liệu đăng nhập vẫn giữ nguyên.

## Lần đầu mở app

1. Nhập **tài khoản FCIM** (tích *Lưu tài khoản và mật khẩu* để không phải nhập lại).
2. Nhập **mã nhân viên** và **mã định danh**.
3. Bấm **Vào bắn lỗi**, cho phép **Camera** nếu quét bằng camera.

## iPhone / iPad

iPhone **không cài được app từ link tải**: Apple chỉ cho cài qua App Store hoặc TestFlight.
Bản iOS được phát qua **TestFlight** – liên hệ người quản lý để nhận lời mời.
